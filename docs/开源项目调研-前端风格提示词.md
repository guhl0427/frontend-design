## 一、调研结论（TL;DR）

「前端风格提示词」赛道在 2026 年已经非常成熟，可分四类：

1. **风格提示词合集（内容源，你的直接对标）** — awesome-design-md、OhMySkills/design-style、MotionSites 等
2. **审美 Skill / 反 AI 味规则（内容深度参考）** — Anthropic 官方 frontend-design、taste-skill、impeccable
3. **提示词模板与写作方法论** — Claude-Design-Cheat-Code、frontend-design-prompt 等
4. **配套工具链（网站克隆/设计提取）** — ai-website-cloner-template、Web to Figma

对做网页最有参考价值的是第 1 类的**内容组织形态**（DESIGN.md 格式、分类目录、预览图 + 一键复制）和第 2 类的**规则写法**（可执行的硬规则清单，而非空泛的"要好看"）。

## 三、对你项目最有价值的 6 个设计启示

1. **DESIGN.md 是事实标准**：生态已收敛到"结构化设计规范文件"格式（颜色/字体/间距/组件规则/反模式），比截图喂 AI 更高效。你的网页内容结构建议对齐这个格式，用户复制后可直接投喂任意 Agent。
2. **提示词 + 预览效果 是标配**：成功项目全部是「prompt.md + GIF/视频/截图预览」组合（xuanxuan-prompts、claude-directory、MotionSites）。没有预览的风格提示词网页没有说服力。
3. **预览加载性能有成熟方案**：xuanxuan-prompts 的「首帧封面图默认展示、点击才加载完整 GIF」值得直接抄，避免一个页面几十个 GIF 拖垮首屏。
4. **提示词本身要工程化**：MotionSites 的 YAML frontmatter（分类/子分类/标签/预览图 URL）+ 正文结构（角色/字体/色板/间距/动效参数）是最佳实践，方便你做筛选、搜索、分类页。
5. **规则要"可执行"而不是"可读的废话"**：taste-skill 的禁令清单（具体到"禁 em-dash、禁三等宽卡片、禁 #000000 纯黑"）远比"设计要高级"有效。你收录/编写提示词时用同样的硬规则标准筛选。
6. **可调参数是差异化方向**：taste-skill 的三拨盘（布局/动效/密度 1-10 档）证明用户想要"可微调的风格"而不是死板模板——你的网页可以做类似的选择器，动态拼装提示词。

## 四、建议的下一步

1. 确定产品形态：纯静态画廊（提示词 + 预览 + 一键复制）即可走快速模式一次成型；若要做「可调参数动态生成提示词」则建议先出 PRD
2. 内容源优先级：OhMySkills/design-style（31 风格，最纯）→ awesome-design-md（73 站点）→ 自写补充中文风格
3. 注意各仓库 License 标注（MIT 可放心收录转载，未核实的先核实再定内容策略）
