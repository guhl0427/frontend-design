# 02 · 数据模型与内容规范

> 数据即产品。本项目 90% 的「业务逻辑」是对一份静态数组的派生，因此先把数据结构与内容约束讲清楚，后面所有模块都可以看成它的消费方。

所有类型定义集中在 `src/types.ts`（136 行，**纯类型，编译后不产生任何运行时代码**）。

---

## 1. 类型全景

```
StyleCategory ─┬─ StyleItem ─┬─ PreviewConfig ─┬─ StylePalette
               │             │                 ├─ ButtonVariant
               │             │                 └─ CardVariant
               │             └─ prompt: string（七段结构约束）
               └─ CATEGORIES（运行时数组，data/styles.ts）

CustomizeOptions ─┬─ CustomizeTuning   （variance / motion / density）
                  ├─ CustomizeBrand    （productName / accentColor / headingFont / bodyFont）
                  └─ CustomizeSections （palette / components / bans）

ViewState      （category / keyword / styleId）—— URL 层的形状
PromptSection  （title / body）—— 提示词切分后的形状
DerivedPreview （config / padding / asymmetric）—— 定制预览的推导结果
```

---

## 2. 字段级说明

### 2.1 `StyleCategory`

9 个字面量联合：`'现代' | '极简' | '复古' | '工业' | '柔和' | '未来' | '艺术' | '国风' | '企业'`。

- 类型层与运行时数组 `CATEGORIES`（`src/data/styles.ts:4-14`）必须同序同集，二者没有编译期绑定，靠 `verify:data` 与人工纪律维持。
- 中文分类名**同时是界面标签与筛选键**；进入 URL 前经 `CATEGORY_SLUGS` 转为英文 slug。

### 2.2 `StylePalette`（8 个必填键）

| 字段 | 用途 | 格式 | 约束 |
| --- | --- | --- | --- |
| `bg` | 预览背景 | `hsl(H S% L%)` / `rgba()` | 必须是可解析色值 |
| `surface` | 卡片 / 面板表面 | 同上，可带 `/ alpha` | 半透明时对比度计算会做合成 |
| `text` | 主文字 | 同上 | 对 `bg` 与 `surface` 均 ≥ 4.5:1 |
| `textMuted` | 次级文字 | 同上 | 同上，**最易踩线**（当前最低 4.54:1） |
| `accent` | 强调色 / CTA | 同上 | 面积应克制，用于主按钮与关键标记 |
| `accentText` | 强调色上的文字 | 同上 | 与 `accent` 对比度需可读 |
| `border` | 边框 | 同上 | — |
| `shadowColor` | 硬阴影 / 发光 | 同上，常带 alpha | — |

色值统一用**空格分隔的现代 HSL 语法**（`hsl(38 76% 62%)`、`hsl(28 25% 6% / 0.50)`）。校验脚本 `parseColor` 同时支持 `hsl()`、`hsla()`、`rgb()`、`rgba()`，但为了让 `Preview` 的内联样式与导出文本一致，新数据一律用空格语法。

### 2.3 `PreviewConfig`

| 字段 | 类型 | 示例 | 说明 |
| --- | --- | --- | --- |
| `palette` | `StylePalette` | — | 见上 |
| `headingFont` | `string` | `'"Archivo Black", sans-serif'` | **必须**在 `index.html` 的 Google Fonts 链接中出现 |
| `bodyFont` | `string` | `'"Space Grotesk", sans-serif'` | 同上 |
| `radius` | `string` | `'2px'` / `'999px'` / `'0px'` | 直接进 CSS，非法值会让样张变形 |
| `borderWidth` | `string` | `'1px'` / `'3px'` | `'0px'` 会在 `Preview` 内被兜底为 `'1px'` |
| `shadow` | `string` | `'4px 4px 0 hsl(0 0% 8%)'` | 仅 `flat` / `acrylic` / `liquid` 三种卡片变体真正使用 |
| `titleWeight` | `number` | `400` / `600` | 数字字重 |
| `titleLetterSpacing` | `string` | `'-0.01em'` | 直接进 CSS |
| `uppercaseTitle` | `boolean` | `true` | 为真时预览标题使用 `nameEn.toUpperCase()` |
| `buttonVariant` | `ButtonVariant` | `'hard'` | 见 §3.1 |
| `cardVariant` | `CardVariant` | `'hard'` | 见 §3.2 |
| `backgroundImage?` | `string` | 渐变 / 网格 | 可选，作为 `background-image` 叠加在 `bg` 上 |

### 2.4 `StyleItem`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `string` | 全局唯一，kebab-case；用于 URL、localStorage、对比集、导出文件名 |
| `nameZh` | `string` | 中文名，卡片主标题 |
| `nameEn` | `string` | 英文名，等宽小字；`uppercaseTitle` 为真时作预览大标题 |
| `category` | `StyleCategory` | 必须属于 `CATEGORIES` |
| `tags` | `string[]` | 非空；`tags[0]` 会显示在预览右上角；全部参与搜索 |
| `summary` | `string` | 一句话摘要，卡片两行截断，也进入 DESIGN.md 引用块 |
| `preview` | `PreviewConfig` | 见上 |
| `prompt` | `string` | 七段结构化正文，模板字符串书写 |

`id` 一旦发布即视为**对外契约**：它出现在分享链接、DESIGN.md 文件名与用户书签里，重命名会造成收藏与深链失效。

### 2.5 定制相关四型

| 类型 | 字段 | 值域 | 语义 |
| --- | --- | --- | --- |
| `CustomizeTuning` | `variance` | 1–10 | 布局实验度：1 对称保守 → 10 艺术化不对称 |
| | `motion` | 1–10 | 动效强度：**只写入提示词文本**，静态预览无法体现 |
| | `density` | 1–10 | 信息密度：1 画廊留白 → 10 仪表盘 |
| `CustomizeBrand` | `productName` | 任意字符串 | 空则沿用风格示例文案 |
| | `accentColor` | hex（`#22c55e`） | 空则沿用风格色；非法 hex 在预览层被忽略 |
| | `headingFont` | `FONT_OPTIONS` 中的一项 | 空则沿用风格推荐 |
| | `bodyFont` | 同上 | 同上 |
| `CustomizeSections` | `palette` / `components` / `bans` | `boolean` | 关闭对应章节不进入生成结果 |
| `CustomizeOptions` | 三者聚合 | — | 默认值见 `DEFAULT_CUSTOMIZE`（三档 5/5/5，品牌全空，开关全开） |

三档参数的语义描述不是插值，而是**四段阶梯式文案**（1–3 / 4–6 / 7–8 / 9–10），文案即提示词内容，位于 `promptComposer.ts` 的 `describeVariance/Motion/Density`。

### 2.6 派生形状

| 类型 | 字段 | 生产者 |
| --- | --- | --- |
| `ViewState` | `category: string` · `keyword: string` · `styleId: string \| null` | `readViewState()` |
| `PromptSection` | `title: string` · `body: string` | `splitPrompt()` |
| `DerivedPreview` | `config: PreviewConfig` · `padding: string` · `asymmetric: boolean` | `derivePreview()` |

## 3. 枚举：变体即视觉语义

### 3.1 `ButtonVariant`（10 种，当前全部被使用）

| 变体 | 视觉规则（摘要） | 使用者示例 |
| --- | --- | --- |
| `solid` | 实心强调色 + 圆角 | `dark-academia`、多数常规风格 |
| `outline` | 透明底 + 边框 + 强调色文字 | `swiss-international` |
| `hard` | 实心 + 2px 描边 + 3px 硬阴影 | `neo-brutalism` |
| `glass` | 白色半透明 + `backdrop-filter: blur(10px)` | `glassmorphism` |
| `gradient` | `linear-gradient(120deg, accent, border)` | `aurora-mesh` |
| `terminal` | 实心 + 等宽语境，文案带 `$ ` 前缀 | `terminal-cli` |
| `pixel` | 直角 + 2px 描边 + 2px 硬阴影 + 字距 | `pixel-art` |
| `clay` | 胶囊 + 外柔影 + 底部内阴影 + 顶部内高光 | `claymorphism` |
| `liquid` | 实心 + 上缘镜面高光 + 细白描边 | `liquid-glass` |
| `riso` | 纯色块 + 无描边 + 第二色版错位硬影 | `risograph` |

`terminal` 变体额外影响**文案**（`'$ 立即开始'`），这类「文案级差异」写死在 `Preview` 里，新增变体时需一并处理。

### 3.2 `CardVariant`（11 种）

`flat`（纯表面色）· `hard`（描边 + 硬影）· `glass`（半透明白 + 模糊）· `inset`（双内阴影浮雕）· `outline`（透明 + 描边）· `pixel`（直角 + 3px 描边）· `sketch`（不规则圆角 + 虚线 + 轻微旋转）· `acrylic`（强模糊 + 饱和提升）· `clay`（体积阴影）· `liquid`（低模糊折射）· `riso`（墨线 + 错位硬影）。

**注意**：`inset` 与 `sketch` 的阴影 / 圆角是硬编码的（分别写死 `hsl(225 25% 78%)` 与 `transform: rotate(-0.6deg)`），不读 `cfg.shadow`。这意味着它们对色板有一定程度的「不听话」—— 是有意为之的质感表达，但换风格时要人工确认观感。

## 4. 内容规范（`verify:data` 会强制检查的部分）

### 4.1 提示词七段结构

`scripts/verify-styles.mjs` 用**字面量字符串**校验以下 7 个标题存在（注意 `#` 的数量），因此章节标题不可改写：

```
# 角色定位          ← 一级标题，唯一
## 设计理念
## 字体方案
## HSL 色板
## 间距与圆角
## 组件规则
## 反模式禁令
```

写法约定：

- 每段内用 `- ` 开头列要点（`StyleDetailPage.renderPromptBody` 会把连续 `- ` 行归组为 `<ul>`）。
- **必须出现具体数值**：hsl 值、字体名与字重、px 值、行高、字距。禁用「现代简洁大气」这类空话。
- 字体只写已在 Google Fonts 引入的家族名；结尾 `sans-serif` / `serif` / `monospace` 兜底。
- 长度：去掉空白后 **300–900 字符**（低于 300 / 高于 900 触发警告而非错误）。
- 禁止出现 `TODO` / `占位` / `待补充` —— 命中即错误。

### 4.2 反 AI 味禁令（跨全库的统一底线）

以下内容在任何一条风格里都不应作为**推荐做法**出现：

- 字体：Inter / Roboto / Arial 等系统默认族（唯一例外是外壳 UI，且外壳用 IBM Plex）；
- 紫色渐变、「科技蓝」满版渐变；
- 三等宽卡片栅格作为唯一布局；
- 纯黑 `#000000` 背景（应用带色相的近黑）；
- 装饰性循环动画、无信息贡献的彩色面积。

这些禁令同时写在每条风格的「反模式禁令」段里，并在 `verify:ui` 中通过导出内容做抽查。

### 4.3 可访问性底线

- `text` 与 `textMuted` 对 `bg` 与 `surface` 的对比度**均需 ≥ 4.5:1**；半透明前景先与背景合成再算。
- 当前全库最低值 4.54（`bento-grid` 的 `textMuted` on `bg`），**已接近下限**，新增或调色时不要指望还有余量。
- 外壳的 `--color-ink-faint` 定在 `hsl(40 5% 52%)`，52% 即为该底色下 4.5:1 的下限，不得再调暗。

### 4.4 字体真实性

`preview.headingFont` / `bodyFont` 里出现的每个非通用族名，都必须在 `index.html` 的 Google Fonts 链接中以 `family=` 形式存在。校验脚本从 HTML 正则提取并逐个比对（大小写不敏感）。当前 27 个族全部命中，`FONT_OPTIONS` 也正好是这 27 个。

## 6. 数据结构不变式 ↔ 校验点对照

| 不变式 | 违反后果 | 谁在守 |
| --- | --- | --- |
| `id` 非空且唯一 | 收藏 / 对比 / 深链全部错位 | `verify:data` §1 |
| `category ∈ CATEGORIES` | 筛选命中不到，该条从任何分类视图消失 | `verify:data` §1 |
| `tags` 非空 | 预览右上角空白，搜索退化 | `verify:data` §1 |
| `preview` 11 个必填键齐全 | `Preview` 出现 `undefined`（渲染为无效 CSS） | `verify:data` §1 |
| `palette` 8 个键齐全 | 同上 | `verify:data` §1 |
| 变体名在枚举内 | `switch` 落到 `default`，样张失去辨识度 | `verify:data` §1 + TS 类型 |
| 七段标题齐全 | 对比视图缺行、DESIGN.md 章节为空 | `verify:data` §1 |
| 字体已引入 | 预览回落到系统字体，与其他样张混淆 | `verify:data` §2 |
| 对比度 ≥ 4.5:1 | 可读性受损（且违反项目底线） | `verify:data` §3 |
| `prompt` 无占位符 | 用户复制到 AI 工具里得到半成品 | `verify:data` §1 |
