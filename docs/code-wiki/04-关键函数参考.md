# 04 · 关键函数参考

> 收录所有具名函数与导出常量。格式：签名 → 行为 → 边界 / 注意点。「内部」标记表示未导出、仅在同文件使用。

## 1. `src/App.tsx`

### 1.1 `resolveById(ids: string[]): StyleItem[]` 〔内部〕

- **行为**：把 id 数组映射为风格对象，**保持传入顺序**，过滤掉已不存在的 id。
- **用途**：对比集、收藏、最近浏览三处共用（三者都只存 id）。
- **注意**：`STYLES` 只有 35 条，O(n·m) 的 `find` 可接受；若数据量上升应换 `Map`。

### 1.2 `filterStyles(styles, filter, keyword, favorites, recent): StyleItem[]` 〔内部〕

```ts
function filterStyles(
  styles: StyleItem[],
  filter: string,
  keyword: string,
  favorites: string[],
  recent: string[],
): StyleItem[]
```

- **行为**：两段式。
  1. 选基底：`filter === FAVORITES_FILTER` → `resolveById(favorites)`；`RECENT_FILTER` → `resolveById(recent)`；否则按 `category` 过滤（`'全部'` 不过滤）。
  2. 关键词：`keyword.trim().toLowerCase()`，对 `[nameZh, nameEn, category, summary, ...tags]` 拼接串做 `includes`。
- **返回**：新数组；收藏 / 最近保持本地数组顺序，分类视图保持数据源顺序。
- **边界**：关键词为空串时直接返回基底（不复制，引用即基底）；大小写不敏感，但**不支持分词或拼音**。

### 1.3 `emptyMessageFor(filter, favorites, recent): string` 〔内部〕

- **行为**：区分三种空态文案 —— 收藏为空、最近为空、关键词无匹配。
- **注意**：文案是产品语的一部分（含操作指引「点击卡片右上角的 ☆ 收藏」），`verify:ui` 对收藏 / 最近两种空态做了互不混淆的断言。

### 1.4 事件处理函数

| 函数 | 行为 | 关键点 |
| --- | --- | --- |
| `handleExportBundle()` | `downloadText(bundleFilename(), buildBundleMarkdown(visibleStyles))` | 空结果直接 return（按钮同时 disabled） |
| `handleExportDesignBundle()` | 同上，走 `buildDesignMdBundle` / `designMdBundleFilename` | 导出的是**当前筛选结果**，非全库 |
| `handleOpen(item)` | 记滚动位置与 `pendingFocusRef` → `setSelected(item)` → `pushRecent` → `pushViewState(state, true)` | 进入详情页即计入「最近浏览」；`pushState` 让后退键等于「返回画廊」 |
| `handleNavigate(item)` | `setSelected(item)` + `pushRecent` | 上一款 / 下一款是同级替换，不压历史记录 |
| `handleBack()` | `isDetailHistoryEntry()` ? `history.back()` : `setSelected(null)` | 深链直达时站内无记录，直接切回画廊而非离开站点 |
| `handleCustomize(item)` | `setCustomizing(item)` | 详情页已是页面，抽屉可以合法叠在它上面，不再先关详情 |
| `handleToggleCompare(item)` | 已在集内 → 移除；已达 `COMPARE_LIMIT` → `setNotice(...)`；否则追加 | 超限是**可见提示**而非静默忽略 |
| `handleRemoveCompare(id)` | 从 `compareIds` 移除 | 使用函数式 `setState` |
| `handleStartCompare()` | 空集 return；`setComparing(true)` | 详情页保留在弹窗之下，关闭对比后仍在原页 |

### 1.5 effect

| effect | 依赖 | 行为 |
| --- | --- | --- |
| URL 回写 | `[activeFilter, keyword, selected]` | 本地筛选（收藏 / 最近）时写 `DEFAULT_VIEW.category`，其余原样写入；`replaceState` 不污染后退栈，并保留 `history.state` 里的详情标记 |
| 前进 / 后退 | `[]` | `popstate` 时只按 `?style=` 同步 `selected`；筛选状态留在内存，不被历史记录覆盖 |
| 焦点归还 | `[selected]` | 回到画廊后恢复 `galleryScrollRef` 的滚动位置，并 `focus({ preventScroll: true })` 到 `[data-cover-id]` 那张封面 |
| 轻提示自动消失 | `[notice]` | 2600ms 后 `setNotice(null)`，清理时 `clearTimeout` |

### 1.6 样式辅助函数

- `tabClass(isActive)`：分类 tab。选中态 = `border-brand`（1px 琥珀下划线）+ `text-ink`；未选中 = 透明边框 + `text-ink-muted`。**选中态不用色块填充**，这是视觉方向的一部分。
- `ghostBtnClass`：工具行按钮（分享 / 导出 / 清空记录）。无边框无底色，靠 `text-ink-faint → hover:text-ink` 区分层级。

## 2. `src/components/Preview.tsx`（内含 `stylePrimitives` 的用法）

> 2.1–2.3 的函数已抽到 `src/components/stylePrimitives.ts`（`Preview` 与 `StyleShowcase` 共用），签名不变。

### 2.1 `stylePrimaryButton(variant, p, radius, borderWidth): CSSProperties` 〔stylePrimitives 导出〕

- **行为**：按 10 种 `ButtonVariant` 返回主按钮的内联样式；未命中的变体走 `default`（实心强调色 + 圆角）。
- **共性 base**：`fontSize 11px` / `fontWeight 600` / `padding 7px 14px` / `lineHeight 1` / `nowrap`。
- **注意**：`outline` 用 `p.accent` 作文字色 + `p.border` 作边框；`glass` 的白色半透明是硬编码（`rgba(255,255,255,0.14)`），与色板无关；`liquid` 的投影硬编码为 `rgba(20, 60, 140, 0.28)`（偏蓝），在暖色风格下需人工复核。

### 2.2 `styleSecondaryButton(variant, p, radius, borderWidth): CSSProperties` 〔stylePrimitives 导出〕

- **行为**：`terminal` 变体返回无边框、`textMuted` 文字；其余返回透明底 + `borderWidth solid p.border`。
- **注意**：两分支的 `fontWeight` 不一致（terminal 未设，其余 500）。

### 2.3 `stylePanel(variant, cfg): CSSProperties` 〔stylePrimitives 导出〕

- **行为**：按 11 种 `CardVariant` 返回面板视觉样式（底色 / 边框 / 圆角 / 阴影），**不含**尺寸与内边距；`Preview` 自己补 `padding: 8px 10px; flex: 1 1 0; minWidth: 0`，`StyleShowcase` 按数据卡 / 特性卡 / CTA 分别给内边距。
- **硬编码例外**（不读 `cfg`）：

| 变体 | 硬编码内容 | 影响 |
| --- | --- | --- |
| `glass` | 白色半透明 + `blur(12px)` | 深色风格上偏亮 |
| `inset` | `inset 3px 3px 6px hsl(225 25% 78%)` / `inset -3px -3px 6px hsl(0 0% 100%)` | 固定为浅色浮雕，深色底上不成立 |
| `sketch` | `border-radius: 255px 15px 225px 15px / 15px 225px 15px 255px` + `rotate(-0.6deg)` | 唯一带旋转的变体 |
| `acrylic` | `rgba(255,255,255,0.55)` + `blur(30px) saturate(120%)` | 与 `glass` 视觉相近，靠模糊强度区分 |
| `liquid` | 顶部内高光 + `rgba(30,45,70,0.12)` 外影 | 靠低模糊（2px）实现折射感 |

### 2.4 `Preview(props): JSX.Element`

- **版式**：固定 216px 高，四段：品牌行（分类徽章 + `tags[0]`）→ 标题区（`nameEn`，按 `uppercaseTitle` 转大写）→ 双按钮（`<span>` 模拟，避免嵌套交互元素）→ 三张迷你卡片（色板 / 字体 / 圆角）。
- **兜底**：`cfg.borderWidth === '0px'` 时内部改用 `'1px'`，防止无边卡片在样张里彻底消失。
- **定制联动**：`asymmetric` 为真时迷你卡片按 `index % 2` 做 `translateY(3px / -9px)`。
- **无障碍**：根节点 `aria-hidden="true"`，`verify:ui` 的 `W3` 断言要求所有卡片预览均如此。

## 3. `src/components/StyleShowcase.tsx`

### 3.1 模块常量

| 常量 | 内容 | 为什么是常量 |
| --- | --- | --- |
| `NAV_LINKS` / `HERO_CHECKS` / `STATS` / `FEATURES` | 导航项、勾选项、三组数据、三张特性卡片文案 | 样张是「同一份落地页换 35 套皮肤」，文案必须恒定，否则各详情页结构会悄悄分叉 |
| `GLYPHS` | `'square' \| 'circle' \| 'diamond'` | 三张卡片的图标位各用一种几何形，按索引取，不做分支 |
| `BAR_HEIGHTS` / `BAR_LABELS` | 7 根柱的百分比高度与星期标签 | 数值固定，任何风格下柱形一致；改文案等于改 35 个详情页但不改结构 |

### 3.2 `glyphStyle(kind, p, radius): CSSProperties` 〔内部〕

- **行为**：16×16 的 `p.accent` 方块；`circle` 改圆角 `999px`，`diamond` 旋转 45°。
- **注意**：用几何形而非图标字体，避免为样张再引入一套字体（`verify:data` 会校验字体是否真的引入）。

### 3.3 `StyleShowcase({ item }): JSX.Element`

- **输入**：只读 `item.preview`（色板 / 字体 / 圆角 / 描边 / 阴影 / 按钮变体 / 卡片变体）。
- **输出**：6 段固定顺序的整页样张 —— 导航 → 主视觉（徽章 + 标题 + 摘要 + 双按钮 + 数据卡）→ 数据条 → 三张特性卡片 → 行动号召 → 页脚，桌面约 930px 高。
- **语义**：根节点 `role="img"` + `aria-label`，内部文案不逐字朗读；模拟按钮全部是 `<span>`，样张里不存在键盘焦点。
- **响应式**：只用流式栅格（`md:grid-cols-[1.1fr_0.9fr]` / `sm:grid-cols-3`），不做字号断点 —— 小屏下样张变成单列，仍然是「一整页」。
- **颜色纪律**：`text` / `textMuted` 只落在 `bg` / `surface` 上，`accentText` 只落在 `accent` 上。这条纪律让 `verify:data` 的 4.5:1 结论对整个样张继续成立。

## 4. `src/components/StyleDetailPage.tsx`

### 4.1 `extractSwatches(p: StylePalette): PaletteSwatch[]` 〔内部〕

固定输出 6 项，顺序：背景 / 表面 / 强调 / 文字 / 次级文字 / 边框。**不含** `accentText` 与 `shadowColor` —— 前者在样张里已体现，后者不是「颜色」而是效果参数。

### 4.2 `renderPromptBody(prompt: string): JSX.Element[]` 〔内部〕

- **行为**：逐行解析。
  - `- ` 开头 → 累积进当前列表；遇到非列表行时先 `flushList` 再处理。
  - `# ` → `<h3>`（页面标题是 h1、区块标题是 h2，故正文最大用 h3）。
  - `## ` → `<h4>`。
  - 其他非空行 → `<p>`；空行直接跳过（间距由 `.prompt-body` 的 CSS 承担）。
- **注意**：这是**受限 Markdown**，不支持粗体 / 链接 / 行内代码。若提示词里出现 `**` 会原样显示。`key` 用行号，内容变化时整体重建（数据不可变，无性能问题）。
- **层级约束**：本函数输出的 h3/h4 是全页标题层级的第三、四级；`verify:ui` 的 `REG2` 断言 `h1 === 1` 且 h3/h4 均存在。

### 4.3 `StyleDetailPage(props)`

- **布局**：顶部条（`sticky top-0 z-40`）→ 标题块 → `figure`（caption + 带边界展示框 + 对应关系说明）→ `lg:grid-cols-[1fr_300px]`（提示词 / 规格侧栏）→ 相邻风格 `nav`。
- **动作分层**：顶部条只有「复制提示词」一个实心块，定制 / 收藏 / 对比 / 分享为文字按钮；下载与 DESIGN.md 导出放在提示词区块头，紧贴它们产出的内容。
- **分享**：`copyLink(buildShareLink(item.id))` —— 只带 `?style=`，保证接收方打开即见该条。
- **下载**：`downloadText(singleFilename(item), buildSingleMarkdown(item))`。
- **DESIGN.md**：`downloadText(designMdFilename(item), buildDesignMd(item))`，文件名恒为 `DESIGN.md`。
- **副作用**：
  1. `document.title` 跟随风格名，卸载时还原；
  2. `item.id` 变化（上一款 / 下一款）时 `scrollTo({ top: 0 })`；
  3. 监听 `Escape` 触发 `onBack`，但**先检查 `[role="dialog"]`**：抽屉 / 对比弹窗打开时让它们的 Esc 独占，否则一次按键会同时关抽屉和退页面。
- **测试锚点**：`data-style-detail` / `data-style-id` / `data-showcase-frame` / `data-swatch` / `nav[aria-label="相邻风格"]`。

## 6. `src/components/CompareDialog.tsx`

### 5.1 `gridTemplate(count: number): string` 〔内部〕

返回 `` `minmax(120px, 160px) repeat(${count}, minmax(0, 1fr))` ``。首列给段落名固定宽度，其余等分且允许收缩到 0（`minmax(0,1fr)` 是防止长文本撑破网格的关键）。

### 5.2 `CompareDialog(props)`

- `sectionLists = items.map(splitPrompt)`，`baseSections = sectionLists[0]`。
- 每行：`section.title` 作行首标签，各列 `find(entry => entry.title === section.title)?.body ?? ''`，空串显示 `—`。

## 7. `src/hooks/`

### 6.1 `useCopy(): { copied: boolean; copy: (text: string) => Promise<void> }`

- **行为**：`await copyToClipboard(text)`，失败则**不置 `copied`**（用户看不到任何反馈，属已知限制）；成功则置真并 2000ms 后复位。
- **重复调用**：先 `clearTimeout` 旧定时器，避免连点导致反馈闪回。
- **卸载**：`useEffect` 清理函数清定时器。

### 6.2 `useFocusTrap<T extends HTMLElement>(): RefObject<T | null>`

| 阶段 | 行为 |
| --- | --- |
| 挂载 | 记录 `document.activeElement` 为 `previous`；聚焦面板内首个可聚焦元素，无则聚焦面板本身（需 `tabIndex={-1}`） |
| Tab | 捕获阶段拦截；列表为空则 `preventDefault`；焦点在面板外 → 拉回首个；在首元素按 Shift+Tab → 跳末尾；在末元素按 Tab → 跳首个 |
| 卸载 | 移除监听；`previous?.isConnected` 时归还焦点 |

- **可聚焦选择器**：`button:not([disabled])`, `[href]`, `input:not([disabled])`, `select:not([disabled])`, `textarea:not([disabled])`, `[tabindex]:not([tabindex="-1"])`，并用 `getClientRects().length > 0` 排除不可见元素。
- **返回类型**：React 19 下 `useRef<T>(null)` 为 `RefObject<T | null>`，不要再收窄成 `RefObject<T>`。

### 6.3 `useLibrary(): UseLibraryResult`

| 成员 | 行为 |
| --- | --- |
| `favorites` / `recent` | 首帧同步读 localStorage（`useState` 初始化函数），避免空列表闪烁 |
| `isFavorite(id)` | `favorites.includes(id)`，`useCallback` 依赖 `favorites` |
| `toggleFavorite(id)` | 存在则移除，否则**插到队首** |
| `pushRecent(id)` | 去重后插队首，`slice(0, RECENT_LIMIT=8)` |
| `clearRecent()` | 置空数组 |

- **持久化**：两个 effect 分别回写；首帧写入与初值相同，不会触发 `storage` 事件。
- **跨标签页**：监听 `storage`，`event.key === null`（`clear()`）或等于对应键时重新读取。`storage` 只在**其他**标签页触发，天然不会自激循环。
- **`readIds` / `writeIds`**（内部）：前者对「非数组 / 非字符串元素 / 非法 JSON / 抛错」全部降级为 `[]`；后者 catch 后静默失败。

## 8. `src/utils/`

### 7.1 `clipboard.ts`

```ts
export async function copyToClipboard(text: string): Promise<boolean>
```

1. 安全上下文且有 `navigator.clipboard` → `writeText`，成功返回 `true`；抛错则继续。
2. 降级：创建 `position: fixed; opacity: 0` 的 `<textarea>`，`select()` 后 `document.execCommand('copy')`，返回其布尔结果。
3. 两次都失败 → `false`。

**注意**：降级路径会短暂移动焦点到 textarea，再移除；在模态里调用时焦点陷阱会在下一次 Tab 时纠正，但 `document.activeElement` 会短暂变成 `body`。

### 7.2 `viewState.ts`

| 函数 | 签名 | 行为 |
| --- | --- | --- |
| `categoryToSlug` | `(category: string) => string \| null` | 9 个中文分类 → 英文 slug；「全部」与哨兵值返回 `null`（不入 URL） |
| `slugToCategory` | `(raw: string \| null) => StyleCategory \| null` | 先按 slug（小写）查，再按中文名精确匹配；空串返回 `null` |
| `readViewState` | `() => ViewState` | 解析 `?cat=&q=&style=`，分类非法回落 `'全部'`；非浏览器环境返回 `DEFAULT_VIEW` |
| `writeViewState` | `(state: ViewState) => void` | 组参 → 省略默认值 → `replaceState` 到 `pathname + ?query + hash` |
| `buildShareLink` | `(styleId: string) => string` | 清空现有 query，只保留 `style`，返回绝对地址 |

**slug 表**：现代 `modern` · 极简 `minimal` · 复古 `retro` · 工业 `industrial` · 柔和 `soft` · 未来 `future` · 艺术 `art` · 国风 `chinese` · 企业 `corporate`。

**为什么必须 slug**：中文分类名在 URL 里会被编码成 `%E7%8E%B0%E4%BB%A3`，分享到 IM / 邮件后不可读且容易被二次转义。`verify:ui` 的 `F1d` 断言 URL 中不含 `%XX`。

### 7.3 `promptSections.ts`

```ts
export interface PromptSection { title: string; body: string }
export function splitPrompt(prompt: string): PromptSection[]
```

- **规则**：标题行匹配 `/^(#{1,2})\s+(.+)$/`；每遇标题先 `flush` 上一段；标题前的散落文本被忽略（当前数据无此情况）；每行先去行尾空白（兼容 CRLF），`body` 再 `trim()`。
- **支持 `#` 与 `##` 两种层级**，且保留原始顺序 —— 对比视图按此顺序出行。

### 7.4 `export.ts`

| 函数 | 签名 | 行为 / 边界 |
| --- | --- | --- |
| `dateStamp` 〔内部〕 | `() => string` | `YYYYMMDD` 本地时间 |
| `dashedDateStamp` 〔内部〕 | `() => string` | `YYYY-MM-DD`，复用 `dateStamp` 切片 |
| `buildSingleMarkdown` | `(item) => string` | 标题 + 4 条元信息 + `---` + 原样 `prompt.trim()` |
| `buildBundleMarkdown` | `(items) => string` | 总标题 + 导出时间 / 数量 + `## 目录`（带 GitHub 风格锚点 `#N-<id>`）+ 逐篇：`## N. 名称` + `> 摘要` + **提示词标题统一降一级**（`#` → `##`）避免与文档大纲冲突 |

| `singleFilename` | `(item) => string` | `style-<id>-<YYYYMMDD>.md` |
| `bundleFilename` | `() => string` | `style-prompts-collection-<YYYYMMDD>.md` |

### 7.5 `promptComposer.ts`

#### 常量与色彩工具

| 函数 | 行为 |
| --- | --- |
| `DEFAULT_CUSTOMIZE` | `tuning 5/5/5`，`brand` 全空串，`sections` 全 `true` |
| `hexToRgb` 〔内部〕 | 支持 `#RGB` 与 `#RRGGBB`；非法返回 `null` |
| `pickAccentText(hex)` | 按 WCAG 相对亮度：`> 0.35` → `hsl(220 25% 10%)`（深色字），否则白色；非法 hex 返回白色 |
| `hexToHslString(hex)` | hex → `hsl(H S% L%)`；非法返回 `null`；`d === 0` 时返回 `hsl(0 0% L%)` |

#### 参数语义（四段阶梯）

| 参数 | 1–3 | 4–6 | 7–8 | 9–10 |
| --- | --- | --- | --- | --- |
| `variance` | 对称居中、等宽对齐 | 允许轻度不对称（左右 6:4） | 主动不对称网格（2+1、错位） | 强艺术化：重叠、对角线、打破网格 |
| `motion` | 仅 hover/focus 即时态 | 一次入场动画（fade + 12px，400ms） | 滚动驱动分段揭示（IntersectionObserver） | 编排式电影级，一个大时刻 |
| `density` | 区块 80px、卡片内边距 ≥32px | 48–64px / 24px | 32px / 16–20px | 16px / 12–16px，正文 13px |

文案中均带具体数值 —— 与「提示词禁止空话」的规范一致。

| 函数 | 行为 |

`composePrompt` 的输出结构：


末尾统一 `\n` 收尾，blocks 之间空一行。

#### 预览推导

| 函数 | 行为 |
| --- | --- |
| `scaleRadius(radius, variance)` 〔内部〕 | `≤3` → `min(n, 8)px`（收紧）；`4–6` → 原值；`≥7` → `min(round(n*1.8), 32)px`；非数值 / `≤0`（如百分比）→ 原样返回 |
| `paddingByDensity(density)` 〔内部〕 | `≤3`→`24px`，`≤6`→`18px`，`≤8`→`15px`，否则 `12px` |
| `derivePreview(item, options)` | 返回 `{ config, padding, asymmetric }` |

`derivePreview` 的覆盖顺序：先拷贝 `item.preview`（含 `palette` 浅拷贝），再按参数改 `radius` / `titleLetterSpacing`（`variance ≥ 8` 时 `-0.03em`），最后按品牌字段覆盖 `accent` + `accentText`（`pickAccentText` 保证可读）/ `headingFont` / `bodyFont`（自动补 `"Noto Sans SC", sans-serif` 兜底）。`asymmetric = variance >= 8`。

**明确不做**：`motion` 不参与预览推导。静态预览无法表达动效，该参数只写进提示词文本。
