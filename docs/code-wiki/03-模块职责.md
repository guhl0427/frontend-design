# 03 · 模块职责

> 本节按文件组织，每个模块给出四件事：**负责什么、接收什么、产出什么、明确不负责什么**。最后一条比前三条更重要 —— 项目里多数「越改越乱」都发生在边界被悄悄突破时。

## 2. 容器层

### 2.1 `src/main.tsx`

- **职责**：取 `#root`，`createRoot(...).render(<StrictMode><App/></StrictMode>)`，引入全局 CSS。
- **不负责**：任何状态、任何逻辑。找不到 `#root` 时抛错而非静默失败。
- **注意**：`StrictMode` 使开发期所有 effect 执行两次（挂载 → 卸载 → 挂载）。因此所有 effect 必须幂等且有清理函数 —— 现有 effect 均满足。

### 2.2 `src/App.tsx`

| 维度 | 内容 |
| --- | --- |
| 职责 | 唯一状态所有者；筛选与搜索；URL 回写；合集导出；对比集管理；模态互斥调度；空态文案；轻提示 |
| 输入 | 无 props。初始状态来自 URL 与 localStorage |
| 输出 | 渲染整页；不返回数据 |
| 依赖 | 数据层（`STYLES`/`CATEGORIES`）、全部组件、`useCopy`、`useLibrary`、`export`、`viewState` |
| 不负责 | 不直接操作剪贴板（走 `useCopy`）、不直接读写 localStorage（走 `useLibrary`）、不生成任何 Markdown 文本（走 `utils/export`）、不定义任何视觉令牌 |

文件顶部的 4 个模块级常量定义了 App 的行为边界：

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `CATEGORY_FILTERS` | `['全部', ...CATEGORIES]` | 筛选栏按钮的完整顺序 |
| `FAVORITES_FILTER` | `'__favorites__'` | 收藏筛选哨兵，**绝不写入 URL** |
| `RECENT_FILTER` | `'__recent__'` | 最近筛选哨兵，同上 |
| `COMPARE_LIMIT` | `3` | 对比集上限，超出时给可见提示 |

布局上还有两个非显然的点：

- 筛选栏 `sticky top-0 z-40`，页头**不**吸顶。`main` 用 `min-h-screen flex-1` 保证任意视口下页面可滚动距离大于筛选栏偏移，否则吸顶会「无处可吸」。
- `main` 的底部内边距随 `compareItems.length` 在 `pb-32` / `pb-8` 间切换，为底部对比条让位。

## 3. 组件层

### 3.1 `StyleCard`（展示 + 局部反馈）

| prop | 类型 | 说明 |
| --- | --- | --- |
| `item` | `StyleItem` | 要展示的风格 |
| `index` | `number` | **数据源中的序号**（1 起），由 App 用 `STYLES.indexOf(item)+1` 计算，筛选后仍稳定 |
| `onOpen` | `(item) => void` | 打开详情 |
| `onCustomize` | `(item) => void` | 打开定制抽屉 |
| `isFavorite` | `boolean` | 收藏态 |
| `onToggleFavorite` | `(id) => void` | 切换收藏 |
| `inCompare` | `boolean` | 是否在对比集 |
| `onToggleCompare` | `(item) => void` | 加入 / 移出对比集 |

- **负责**：预览样张的点击入口、编号 / 中英文名 / 分类 / 摘要 / 标签、复制提示词与「已复制」反馈（自己调 `useCopy`）。
- **不负责**：不持有收藏或对比状态（受控），不做任何筛选判断。
- **无障碍**：预览区是 `<button aria-label="查看「X」提示词详情">`；复制结果另有 `sr-only role="status" aria-live="polite"` 区域播报 —— 仅换按钮文字对读屏不友好。
- **结构约束**：**任何叠在样张上的控件必须是该 `<button>` 的兄弟节点**，否则产生 button 嵌套（非法 HTML）。星标因此被放在元信息行而非样张右上角。

### 3.2 `Preview`（渲染器，被三处复用）

| prop | 类型 | 说明 |
| --- | --- | --- |
| `item` | `StyleItem` | 提供 `nameZh` / `nameEn` / `category` / `tags[0]` |
| `preview?` | `PreviewConfig` | 覆盖配置；缺省用 `item.preview`（定制器传 `derivePreview().config`） |
| `padding?` | `string` | 覆盖容器内边距，缺省 `'18px'` |
| `asymmetric?` | `boolean` | 迷你卡片交错位移（`variance ≥ 8` 时由定制器置真） |

- **负责**：把「色板 + 字体 + 圆角 + 边框 + 阴影 + 组件变体」翻译成一段固定版式的迷你 hero（顶栏 → 标题区 → 双按钮 → 三张迷你卡片），高度固定 216px。
- **不负责**：不响应式、不做动画、不接收任何文本内容（标题取 `nameEn`，副标题是固定文案）。
- **无障碍**：根节点 `aria-hidden="true"` —— 纯装饰，交互语义由外层按钮承载。
- **复用点**：`StyleCard`、`Customizer`、`CompareDialog`。改动此文件等于同时改动 35 张卡片 + 定制预览 + 对比视图三处。

### 3.3 `PromptDetail`（详情弹窗）

| prop | 类型 | 说明 |
| --- | --- | --- |
| `item` | `StyleItem` | 展示目标 |
| `onClose` | `() => void` | 关闭 |
| `onCustomize` | `(item) => void` | 转入定制 |
| `isFavorite` / `onToggleFavorite` | 同卡片 | 收藏 |
| `inCompare` / `onToggleCompare` | 同卡片 | 对比 |

- **负责**：完整提示词渲染（`#`→`h3`、`##`→`h4`、`- ` 行→`ul/li`）、6 项色板展示（棋盘格底衬 + 真实色值覆盖，让半透明色可被正确解读）、字体样张、8 个动作（复制 / 定制 / 收藏 / 对比 / 导出 DESIGN.md / 分享 / 下载 / 关闭）。
- **副作用**：挂载时锁 `body.overflow`；监听 `Escape`；卸载时恢复。焦点由 `useFocusTrap` 管理。
- **不负责**：不生成导出文本（调 `export`），不改 App 状态（全走回调）。
- **测试锚点**：色板行带 `data-swatch="<名称>"`，`verify:ui` 依赖它而非类名。

### 3.4 `Customizer`（定制抽屉）

| prop | 类型 | 说明 |
| --- | --- | --- |
| `item` | `StyleItem` | 被定制的基底风格 |
| `onClose` | `() => void` | 关闭 |

- **负责**：三档滑块（1–10）、品牌占位符（名称 / 主色 / 两处字体）、三个段落开关、实时预览、生成结果预览与字符数、复制 / 下载 `-custom.md` / 重置。
- **副作用**：入场动画（`requestAnimationFrame` 置 `entered`，`transform: translateX` 280ms）；锁滚动；`Escape` 关闭。
- **关键实现**：`options` 是**唯一真实来源**，`derived`（预览配置）与 `prompt`（文本结果）都由它 `useMemo` 派生，二者不可能不同步。
- **`isDefault` 用 `JSON.stringify` 对比**：字段少且均为原始值，够用；若将来加入数组或对象字段需换比较方式。
- **不负责**：不持久化定制参数（关闭即丢失，属已知取舍）。

### 3.5 `CompareTray`（底部对比条）

| prop | 类型 | 说明 |
| --- | --- | --- |
| `items` | `StyleItem[]` | 已选风格（按加入顺序） |
| `onRemove` | `(id) => void` | 单项移除 |
| `onClear` | `() => void` | 清空 |
| `onStart` | `() => void` | 打开对比视图 |

- **负责**：chip 列表、开始对比（带数量）、清空。
- **特殊行为**：`items.length === 0` 时返回 `<></>`，DOM 中不产生任何节点 —— `verify:ui` 的「移除后整条消失」断言依赖此行为。
- **层级**：`z-30`，位于所有 `z-50` 模态之下。

### 3.6 `CompareDialog`（对比模态）

| prop | 类型 | 说明 |
| --- | --- | --- |
| `items` | `StyleItem[]` | 2–3 条（1 条也能打开，但无对比意义） |
| `onClose` | `() => void` | 关闭 |

- **负责**：首列段落标题 + 每款一列的网格；上半部分并排 `Preview`，下半部分按段落横向对照；缺失段落显示 `—`。
- **对齐规则**：段落顺序**以第一条风格为准**（`sectionLists[0]`），其他列按标题查找，找不到即空。所有行共用同一 `gridTemplateColumns`（`minmax(120px,160px) repeat(n, minmax(0,1fr))`），行内不加水平内边距，否则正文列会相对预览列整体偏移。
- **副作用**：`Escape` 关闭 + 锁滚动，与 `PromptDetail` 一致。
- **测试锚点**：每行带 `data-compare-row="<段落标题>"`。

## 4. Hook 层

| Hook | 职责 | 副作用 | 不负责 |
| --- | --- | --- | --- |
| `useCopy` | 调 `copyToClipboard`，维护 2s 的 `copied` | `setTimeout`（重复调用先清旧定时器；卸载时清理） | 不负责降级策略本身（在 `utils/clipboard`） |
| `useFocusTrap` | 打开时聚焦面板首个可聚焦元素；Tab / Shift+Tab 循环；关闭时归还焦点 | `document` 捕获阶段 `keydown`；卸载时 `previous.focus()` | 不处理 `Escape`（各组件自己监听）、不锁滚动 |
| `useLibrary` | 收藏 / 最近的读写与跨标签同步 | 两个 `useEffect` 回写 localStorage；一个 `storage` 监听 | 不负责把 id 映射成对象（App 的 `resolveById`）、不做任何 UI 反馈 |

`useFocusTrap` 的三个实现细节值得记住：

1. 可聚焦元素需通过 `getClientRects().length > 0` 过滤（排除 `display:none`）；
2. `keydown` 绑定在 `document` 且 `capture = true`，保证在 React 合成事件之前拦截；
3. 归还焦点前检查 `previous?.isConnected` —— 深链直达时触发元素可能不存在（页面刚加载），此时静默跳过。

## 5. 工具层

| 模块 | 职责 | 纯函数？ | 触碰浏览器 API |
| --- | --- | --- | --- |
| `utils/clipboard` | 写剪贴板：优先 `navigator.clipboard`（需安全上下文），失败降级到隐藏 textarea + `execCommand` | 否 | 是（DOM） |
| `utils/viewState` | URL ↔ `ViewState`；分类 ↔ slug 映射；生成分享链接 | 除 `read/writeViewState` 外是 | 是（`window`） |
| `utils/promptSections` | 用 `/^(#{1,2})\s+(.+)$/` 把提示词切成有序段落 | **是** | 否 |
| `utils/export` | 生成三种导出文本 + 触发下载 | 生成函数是，`downloadText` 否 | 是（`Blob`/`a`） |
| `utils/promptComposer` | 组装定制提示词；推导定制预览配置；hex ↔ hsl / 亮度判断 | **是** | 否 |

**为什么 `promptSections` 要独立成模块**：对比视图与 DESIGN.md 导出都需要「按标题取段落」，若各自实现正则，标题格式一变就会两处不同步。现在唯一实现点在此。

## 6. 模块边界规则（评审时的检查项）

1. **组件不 import `App`**，也不 import 兄弟组件的内部常量。
2. **组件不直接读写 `localStorage` / `history` / `navigator.clipboard`**，一律经 hook 或 utils。
3. **utils 不 import hooks / components / data**（只用 `types`）。
4. **`Preview` 不 import 任何 hook 或 utils** —— 它是纯展示，输入只有 props。
5. **只有 `App` 知道筛选哨兵常量**；组件收到的是已解析数据。
6. **只有 `index.css` 定义颜色 / 字体 / 圆角令牌**；组件里出现的硬编码色值必须是预览数据或语义化例外（如棋盘格底衬的灰阶、`bg-black/70` 遮罩）。
